#SoundScape
A simple music website built using HTML, CSS, JavaScript, and Bootstrap. This project replicates the basic UI and functionality of Spotify, allowing users to browse and play music.

## Features

- Responsive
- Music player with play, pause, and skip functionality
- Playlist and album display
- Search functionality
- Mobile-friendly design

## Technologies Used

- **HTML** - Structuring the web pages
- **CSS** - Styling the UI
- **JavaScript** - Adding interactivity
- **Bootstrap** - Making the design responsive and visually appealing



## Future Enhancements

- Integrate an API for real-time music streaming
- Add user authentication
- Create a backend for user playlists
